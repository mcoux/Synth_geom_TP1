# Synth_geom_TP1

Les exercices sont sous la forme de Gameobjects de la scène principale. Chacun contient un script avec le code correspondant.
Pour afficher le rendu des exercices, il faut lancer la scène principale. La plupart des paramètres des exercices sont en SerializeField, donc modifiables sans ouvrir le code.

### Dépôt créé dans le cadre d'un cours de modélisation 3D sur Unity
